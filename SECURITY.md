# Segurança

## Escopo

O Marcos DemoFlow grava janelas e automatiza interações locais com mouse, teclado e Google Chrome. Ele não foi projetado para contornar autenticação, explorar falhas de segurança ou operar em sistemas sem autorização.

## Uso responsável

- grave apenas ambientes em que você tenha permissão;
- evite deixar senhas, tokens, chaves de API ou dados pessoais visíveis;
- confira a aba escolhida antes de iniciar a automação;
- use `F8` ou mova o mouse para o canto superior esquerdo para interromper uma execução inesperada;
- revise o vídeo antes de publicar ou enviar para terceiros.

## Permissões do sistema

No macOS, recursos de gravação e automação podem exigir permissões de Acessibilidade, Gravação da Tela e Automação. Conceda apenas ao Python ou ao aplicativo que você instalou e revogue as permissões quando não forem mais necessárias.

## Reportar uma vulnerabilidade

Não publique detalhes sensíveis em uma issue pública. Envie o relato para **Contato@marcosolter.com.br** com passos de reprodução, impacto esperado e versão afetada.
